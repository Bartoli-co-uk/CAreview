# Support

## Using the skeleton

Read [`README.md`](README.md), [`START_HERE.md`](START_HERE.md), and [`docs/workflow.md`](docs/workflow.md) first. For a reproducible problem with the skeleton, open a GitHub issue using the most relevant form and include:

- the affected commit;
- operating system and tool versions;
- what you expected and what happened;
- the smallest safe reproduction; and
- validation output with secrets removed.

General project-design decisions remain with the project owner. Provider authentication, billing, availability, and account issues belong with the relevant provider.

Support is best effort. There is no guaranteed response time, compatibility promise, or production-readiness assurance.

Never post secrets or private vulnerability details. Follow [`SECURITY.md`](SECURITY.md) for those reports.
